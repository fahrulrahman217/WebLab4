Penjelasan

- Header
  Bagian header berfungsi menampilkan identitas pemilik website, yaitu Fahrul Rahman sebagai mahasiswa Teknik Informatika. Elemen h1> digunakan untuk menampilkan nama, sedangkan <p> digunakan untuk menampilkan keterangan atau deskripsi singkat.
- Navigasi
  Navigasi digunakan untuk memudahkan pengunjung berpindah dari satu halaman ke halaman lainnya. Menu Home menuju halaman utama, About menuju halaman profil, dan Contact menuju halaman kontak. Class active menandakan bahwa halaman About sedang dibuka.
- Hero About Me
  Bagian hero merupakan area pengenalan utama pada halaman About. Bagian ini berisi judul About Me dan informasi singkat mengenai pemilik website, termasuk jurusan kuliah serta minat dalam pemrograman dan teknologi digital.
- Deskripsi Singkat
  Bagian ini menjelaskan kemampuan dan kegiatan belajar pemilik website. Elemen Article digunakan untuk mengelompokkan konten yang berdiri sebagai sebuah bagian informasi, sedangkan H2 menjadi judul dan P berisi penjelasan.
- Portofolio
  Bagian portofolio menampilkan contoh proyek atau keterampilan yang sedang dipelajari. Terdapat tiga kategori utama:

1. Halaman HTML: mempelajari struktur halaman website, paragraf, tautan, dan tabel.
2. Desain CSS: mempelajari pengaturan warna, tipografi, navigasi, dan tata letak.
3. Program Dasar: mempelajari logika pemrograman melalui program sederhana.
   Class row digunakan untuk mengelompokkan kartu, sedangkan class box portfolio-card mengatur tampilan setiap kartu portofolio menggunakan CSS.

- Tujuan Saya
  Bagian ini menjelaskan tujuan pemilik website dalam mengembangkan keterampilan di bidang teknologi informasi. Tombol Hubungi Saya mengarahkan pengunjung ke halaman Contact agar dapat melihat informasi kontak atau mengisi formulir pesan
- Footer
  Footer merupakan bagian paling bawah website yang menampilkan informasi hak cipta, nama pemilik website, jurusan, dan universitas. Simbol &copy digunakan untuk menampilkan simbol ©.

Penjelasan

- Hero
  Bagian Hero menampilkan judul dan pengantar singkat pada halaman Contact agar pengunjung mengetahui bahwa halaman tersebut digunakan untuk menghubungi pemilik website.
- Informasi Kontak
  Bagian ini berisi informasi kontak pemilik website, seperti alamat email atau informasi lain yang dapat digunakan pengunjung untuk menghubungi pemilik website.
- Formulir Kontak
  Formulir kontak digunakan agar pengunjung dapat mengisi data seperti nama, email, dan pesan yang ingin disampaikan.
- Tombol Kirim
  Tombol Kirim digunakan untuk mengirim pesan yang telah diisi pada formulir. Agar pesan benar-benar terkirim, tombol ini perlu dihubungkan dengan fungsi pemrosesan, misalnya menggunakan JavaScript atau layanan backend.
