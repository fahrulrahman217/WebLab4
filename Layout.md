## Isi Folder

- `home.html` — halaman utama yang menerapkan layout header, navigasi, hero, main content, sidebar, dan footer.
- `about.html` — halaman About berisi deskripsi singkat, portofolio, dan tujuan.
- `kontak.html` — halaman Contact berisi informasi kontak dan formulir nama, email, subjek, serta pesan.
- `style.css` — stylesheet bersama untuk seluruh halaman.

## Langkah Pengerjaan

1. Membuat folder proyek bernama `Lab4Web`.
2. Membuat `home.html`, `about.html`, `kontak.html`, dan `style.css`.
3. Menghubungkan setiap halaman ke `style.css` dengan tag `<link rel="stylesheet" href="style.css">`.
4. Membuat navigasi menggunakan elemen semantik `<nav>`.
5. Menggunakan elemen `<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, dan `<footer>` untuk menyusun layout.
6. Menggunakan CSS `float`, `clear`, margin, padding, dan `box-sizing` untuk tata letak halaman utama.
7. Membuat halaman About dengan deskripsi, portofolio, dan tujuan.
8. Membuat halaman Contact dengan formulir nama, email, subjek, dan pesan.
9. Menambahkan aturan media query agar halaman lebih nyaman dilihat pada layar kecil.
10. Membuka `home.html` di browser dan menguji tautan navigasi ke halaman About dan Contact.

## Cara Menjalankan

Buka file `home.html` di browser. Gunakan menu navigasi untuk membuka halaman About dan Contact.

## Catatan

Formulir Contact adalah contoh antarmuka front-end. Karena belum dihubungkan dengan backend atau layanan email, tombol Kirim Pesan belum menyimpan atau mengirim pesan.
